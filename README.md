# China Studies Trainer — документация проекта

[![Проверки](https://github.com/bronik04/china-studies-trainer/actions/workflows/checks.yml/badge.svg)](https://github.com/bronik04/china-studies-trainer/actions/workflows/checks.yml)

**Приложение:** https://bronik04.github.io/china-studies-trainer/

Стартовый комплект документации для веб-приложения, которое помогает школьникам изучать страноведение Китая: административное деление, города, географию, историю и культуру.

## Что входит в MVP

- интерактивная SVG-карта провинциального уровня Китая;
- режимы «найди на карте», «назови регион» и «пары: регион — столица»;
- карточки регионов, учёт попыток и повторение ошибок;
- локальное сохранение прогресса ученика.

## Как работать AI-исполнителю

1. Начать с [AGENTS.md](AGENTS.md), затем прочитать PRODUCT.md, MVP.md и SPEC.md.
2. Сверять решения с MAP_SPEC.md, DATA_MODEL.md и ACCEPTANCE_CRITERIA.md.
3. Не добавлять функции вне MVP, пока это не согласовано.
4. После изменений запускать проверки из TESTING.md и обновлять CHANGELOG.md.

## Рекомендуемый стек

TypeScript, React, Vite, SVG, Vitest и Playwright. Сервер и авторизация не нужны в первой версии: данные и прогресс могут храниться локально. Стек — рекомендация, а не обязательное требование; важнее выполнение спецификации и доступность для школьников.

## Навигация

| Документ | Назначение |
| --- | --- |
| PRODUCT.md / MVP.md | продукт и границы первой версии |
| SPEC.md | функциональные требования |
| MAP_SPEC.md | правила работы карты |
| DATA_MODEL.md | структуры данных и контракты |
| UI_UX.md / DESIGN_SYSTEM.md | интерфейс и визуальные правила |
| TESTING.md | стратегия проверки |
| ROADMAP.md | развитие после MVP |

Папки `docs/screens`, `docs/examples` и `docs/sources` предназначены для макетов, примеров контента и проверенных источников соответственно.
