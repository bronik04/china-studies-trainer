# Дизайн-система

## Характер

Спокойный учебный интерфейс: светлый тёплый фон, глубокий чернильный текст, один красный акцент, приглушённые нефритовые и золотистые вспомогательные оттенки. Национальные мотивы не должны превращаться в декор, мешающий чтению.

## Токены

| Роль | Значение |
| --- | --- |
| Фон | `#FFFDF8` |
| Основной текст | `#1F2937` |
| Акцент | `#B42318` |
| Успех | `#087443` |
| Ошибка | `#B42318` |
| Фокус | `#175CD3` |
| Граница | `#D0D5DD` |

Не используйте только эти цвета для передачи статуса. Контраст текста с фоном — 4.5:1 или выше.

## Типографика и сетка

Системный sans-serif; китайские символы должны иметь надёжный fallback. Базовый размер текста 16 px, заголовок экрана 28–32 px, межстрочный интервал обычного текста 1.5. Шкала отступов: 4, 8, 12, 16, 24, 32, 48 px. Контент ограничен шириной 1120 px.

## Компоненты

Кнопки: primary, secondary, text; у каждого есть `hover`, `focus`, `disabled`, `loading`. Карточки имеют ясный заголовок и ровно одну основную цель. Результат вопроса — отдельный компонент с иконкой, текстом и пояснением. Никаких иконок без доступного названия.
