# Критерии приёмки MVP

## Контент и карта

- [ ] В справочнике 34 единицы провинциального уровня, у каждой есть русское и китайское названия, пиньинь, центр и источник.
- [ ] Каждому региону соответствует ровно одна интерактивная область SVG.
- [ ] Карта работает мышью, касанием и клавиатурой; есть список-альтернатива.

## Учебный сценарий

- [ ] Пользователь проходит раунд из 10 уникальных вопросов во всех трёх режимах.
- [ ] После ответа видны текстовый результат, верный ответ и объяснение.
- [ ] Неверные ответы появляются при «Повторить ошибки» после раунда.
- [ ] Уровни 2–4 открываются по правилам из SPEC.md.
- [ ] Прогресс остаётся после перезагрузки; при ошибке хранилища упражнение не ломается.

## Качество

- [ ] Основной поток соответствует WCAG 2.2 AA: фокус, контраст, клавиатура, отсутствие опоры только на цвет.
- [ ] На ширине 320 px нет потери основной функции.
- [ ] Сборка, линтер и автоматические тесты проходят.
- [ ] Нет блокирующих фактических ошибок и контент имеет документированные источники.
- [ ] CHANGELOG.md отражает версию и существенные изменения.
