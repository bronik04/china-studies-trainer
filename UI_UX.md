# UI/UX

## Основные экраны

1. Главная: закреплённая шапка с разделами, герой со справочной картой и единственным главным шагом, карточки шести игр (четыре рабочих, две готовятся), витрина коллекций с фильтром по группам, «Содержание» и «Источники». Игры равноправны и открыты все сразу: это разные занятия, а не ступени одной лестницы. Каждая секция занимает экран под шапкой; на узком экране секция растёт по содержимому, а не обрезает его.
2. Атлас: карта во весь кадр, справа панель с карточкой выбранного региона и списком с поиском. Зум — в углу самой карты.
3. Коллекции: раздел по трём группам и страница коллекции — слева описание, справка и фотографии, справа карта регионов коллекции и кнопка «Спросить эти регионы».
4. Упражнение — оболочка `RoundStage`: карта занимает почти весь кадр, плашка вопроса плавает сверху по центру, тонкая служебная строка снизу (секундомер, счёт, след раунда, «Прервать раунд», «Во весь экран»). В играх с вариантами ответ выбирается из горизонтальной полосы тёмных кнопок под картой, в том числе клавишами 1–4; равнозначный список регионов открывается из панели «Ответить из списка».
5. Обратная связь: после ошибки плашка вопроса на ~2 секунды становится плашкой ответа и называет верный ответ; кнопки «Далее» нет — раунд переходит дальше сам. Полный разбор ошибок — на итогах.
6. Итог: точность, время, список ошибок и действия «Повторить ошибки», «Новый раунд».

## Приоритеты интерфейса

На экране всегда очевиден один главный следующий шаг. Экран упражнения не прокручивается: вопрос, карта и результат видны одновременно. Разбор ошибки показывает плашка ответа на месте плашки вопроса — глаз не переезжает после ответа. Первая остановка Tab — сам ответ, а не служебные ссылки. «Прервать раунд» стоит в подвале, дальше всех от ответов. В мобильной версии блок вопроса липнет к верху кадра, карта занимает ширину контейнера, а равнозначный список раскрыт: при 375 px он единственный способ попасть в мелкий регион. Области касания — не менее 44×44 CSS px.

## Тон

Поддерживающий и точный: «Почти! Правильный ответ — Юньнань.» Вместо «Ты ошибся» — «Этот регион стоит повторить». Не использовать таймер по умолчанию и не наказывать за медленный ответ.

## Доступность

Соответствовать WCAG 2.2 AA для базовых сценариев: видимый фокус, контраст, управление с клавиатуры, семантические кнопки, `aria-live` для результата, смысл без цвета, адаптация текста до 200%. Для карты предоставить равнозначный режим выбора из списка регионов.
