# Макеты экранов

Сохраняйте здесь утверждённые макеты и экспортированные изображения экранов. Имена: `01-start-v1.png`, `02-exercise-map-v1.png`, `03-result-v1.png`. Для каждого файла добавляйте краткое описание: дата, автор, версия, сценарий и ссылка на решение в DECISIONS.md.

Макет не заменяет требования UI_UX.md и доступности: при расхождении приоритет у спецификации и критериев приёмки.

## 05-physical-relief-v1.html

- Дата: 2026-08-25. Автор: Claude (сессия с владельцем продукта).
- Сценарий: физическая карта в атласе — поверхность рельефа (три варианта) и кнопки масштаба (три вида).
- Геометрия настоящая: 34 контура из `public/maps/china-provinces.svg`, реки и озёра из `src/map/physical-geometry.ts`, полосы высот посчитаны по ETOPO1 (NOAA, public domain) в проекции карты.
- Решение владельца о направлении: настоящая поверхность высот вместо именованных форм Natural Earth; знаки масштаба вместо слов, в пустом верхнем левом углу. Выбор варианта — в DECISIONS.md.
