# Шрифты

Три семейства под SIL Open Font License 1.1. В репозитории лежат подмножества,
нарезанные под знаки этого приложения, — полные файлы не хранятся.

| шрифт | автор | источник |
| --- | --- | --- |
| Prata | Cyreal | https://fonts.google.com/specimen/Prata |
| Golos Text | Paratype | https://fonts.google.com/specimen/Golos+Text |
| Noto Serif SC | Google | https://fonts.google.com/noto/specimen/Noto+Serif+SC |

Дата получения: 2026-08-04. Файлы: `src/assets/fonts/`, суммарно 71.6 КБ.

## Как перегенерировать

```
npm run generate:fonts
```

Скрипт запрашивает у Google Fonts подмножество по параметру `text=`, проверяет
покрытие разбором таблицы `cmap` и кладёт woff2 в `src/assets/fonts/`. Нужен
интернет; само приложение и сборка без него работают.

Проверять покрытие обязательно: `unicode-range` в ответе Google повторяет
запрошенное, а не отвечает, что вошло. Контрольный запрос трёх знаков `中国А`
у Prata возвращает «покрыто всё», хотя иероглифов в Prata нет.

Если сборка упала с «Знак вне подмножества» — в контенте появился знак,
которого нет в файлах. Перегенерировать и закоммитить и шрифты, и
`scripts/font-coverage.json`.

## Что какой шрифт покрывает

Проверено разбором `cmap` у настоящих файлов:

| шрифт | чего нет из инвентаря приложения |
| --- | --- |
| Prata 400 | `Ā ā ē ě ī ō ū ǎ ǔ` и `→ ↻ ≈ ○ ● ✓` |
| Golos Text 400/500/700 | `ǎ ǔ` и `↻ ○ ● ✓` |
| Noto Serif SC 400 | только `↻` |

Поэтому пиньинь и значки набирает китайский шрифт: его латиница нарисована
ровно под тональные знаки. Разметку даёт `langOf` в
`src/domain/representations.ts`, состав требований — `scripts/font-manifest.ts`.

Единственное исключение — `↻`, значок «стоит повторить» на карточке ответа.
Его нет ни в одном из трёх шрифтов, он берётся из системы; смысл несут
`aria-label` значка и заголовок словами рядом.
