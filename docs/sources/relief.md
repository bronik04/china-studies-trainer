# Источник высот физической карты

Поверхность рельефа заливается по высоте, а не по именованным формам. Полосы
высот собирает `npm run generate:relief` в `src/map/relief-bands.ts`.

| Поле | Значение |
| --- | --- |
| Идентификатор | `etopo1-global-relief` |
| Название | ETOPO1 Global Relief Model |
| Организация | NOAA National Centers for Environmental Information |
| Исходный URL | https://www.ncei.noaa.gov/products/etopo-global-relief-model |
| Доступ | ERDDAP, набор `etopo180`: https://coastwatch.pfeg.noaa.gov/erddap/griddap/etopo180.html |
| Лицензия | Public domain (работа правительства США) |
| Дата получения | 2026-08-25 |
| Изменения | Взята высота в метрах по сетке 0.1° в области 72–137° в. д., 15–55° с. ш. — 261 051 узел. Сетка сглажена средним по 3×3 дважды, изолинии шести порогов (200, 500, 1000, 2000, 3000, 4000 м) построены методом марширующих квадратов, упрощены Дугласом — Пекером и переведены в систему координат карты. |
| Покрытие | Заливка суши на физическом виде карты и шкала высот под ней. |

Полная модель в репозиторий не кладётся: выжимка снимается
`npm run extract:relief` и коммитится в `scripts/data/relief-source.json`.
Команде нужна сеть, и в сборку она не входит — во время сборки и во время
раунда проект сетевых запросов не делает.

Шаг сетки 0.1° — примерно 11 км по широте. Карта рисуется около 835 CSS px в
ширину, то есть один пиксель — примерно 9 км: сетка мельче того, что видно на
экране, и запас точности в ней есть.
