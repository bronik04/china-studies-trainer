# Реестр источников

Здесь хранятся проверенные ссылки и заметки об их использовании. Для каждого источника создайте Markdown-файл или запись в `sources.md` с полями: `id`, название, организация/автор, URL, дата обращения, лицензия (для карты и изображений), какие поля он подтверждает, и дата последней проверки.

Предпочтительны официальные статистические/образовательные материалы, академические издательства, музейные и библиотечные ресурсы. Не используйте поисковую выдачу, непроверенные блоги или материалы без ясной лицензии как единственный источник факта.

Пример идентификатора: `national-bureau-statistics-2026`.

## Файлы реестра

- `sources.md` — записи о текстовых источниках фактов.
- `map.md` — геометрия карты регионов.
- `physical.md` — реки, формы рельефа и озёра физической карты.
- `relief.md` — высоты, по которым заливается физическая карта.
- `cities.md` — города.
- `dynasties.md` — династии, их столицы и правители.
- `photos.md` — снимки коллекций, их авторы и лицензии; файл генерируется.
- `fonts.md` — шрифты и их лицензии.
