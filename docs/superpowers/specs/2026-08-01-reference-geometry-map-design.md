# Карта с реальными границами — дизайн

## Контекст

Текущий SVG использует схематические полигоны. Владелец продукта ожидает визуальное сходство с утверждённым референсом: реальные границы единиц провинциального уровня и его цветовую схему.

## Решение

Локальный SVG перерабатывается из файла `China province-level divisions.svg` автора SilverStar54 (CC BY-SA 4.0):

- сохраняются реальные контуры 34 единиц провинциального уровня и категории цветов референса;
- удаляются английские подписи, номерные выноски, легенда, рамка, метаданные редактора и внешние ссылки;
- каждая учебная единица получает ровно один `path` с `id` и `data-region-id`, равными `Region.mapAreaId`;
- для Пекина, Тяньцзиня, Шанхая, Гонконга и Макао добавляются увеличенные прозрачные зоны касания, не изменяющие видимые реальные контуры;
- сохраняются `tabindex="0"`, `role="button"`, русско-китайское доступное имя, выбор мышью/касанием/Enter/Space, Escape, текстовый список и масштаб.

## Границы и стиль

Цвета остаются семантикой исходного референса: провинции, автономные районы, города центрального подчинения и САР различаются фоном. Выбранная область получает контрастную обводку и текстовое объявление; смысл выбора не кодируется одним цветом. Карта не содержит текстовых подписей внутри SVG: названия доступны через фокусируемые области и русский текстовый список.

## Данные, лицензия и проверка

Источник, автор, URL, CC BY-SA 4.0, дата получения и факт адаптации остаются в `docs/sources/map.md`. SVG хранится локально, не содержит скриптов, внешних шрифтов или сетевых ссылок. Валидатор по-прежнему требует точного соответствия 34 `mapAreaId` каталога и 34 `data-region-id` карты.

## Проверки

До изменения добавляются тесты, которые проверяют наличие реальной SVG-области у региона и не позволяют декорации попасть в контракт 34 областей. После замены выполняются `npm test`, `npm run lint`, `npm run validate:content`, `npm run validate:map`, `npm run build`, `git diff --check`; вручную сверяются вид с референсом, выбор, фокус, масштаб, список и ширина 320 px.

## Ограничение

Карта — учебная визуализация на основе исходника 2023 года. Она не является юридической или навигационной картой и не добавляет проверку ответов в упражнениях.
