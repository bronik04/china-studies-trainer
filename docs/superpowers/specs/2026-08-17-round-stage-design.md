# Оболочка RoundStage: картоцентричный игровой экран и полноэкранный режим

Дата: 2026-08-17. Статус: согласован с владельцем продукта в сессии брейншторма.

## Контекст и цель

Игровые экраны сегодня свёрстаны двумя колонками: слева вопрос, варианты,
разбор ошибки и след раунда, справа карта. Владелец продукта дал два референса
и попросил переосмыслить экраны раундов под них, адаптировав к нашему дизайну:

- **ekvis.com/ru/g-cn-02** (столицы провинций) — служебная строка «счёт /
  точность / время / вопрос» над картой, кнопка настоящего полноэкранного
  режима;
- **motovskikh.ru/china** (регионы) — карта как сцена, вопрос поверх неё,
  минимум интерфейса, после ошибки регионы красятся и игра едет дальше без
  паузы.

Цель: карта занимает весь кадр, интерфейс плавает поверх неё, у раунда
появляется настоящий полноэкранный режим. Механика раундов и домен не
меняются.

## Решения владельца продукта

Приняты в диалоге 2026-08-17 (макеты — `.superpowers/brainstorm/…`, в git не
входят):

1. **Переосмысляются все четыре вида раундов**: регионы (`ExerciseRound`),
   города (`CityRound`), физическая карта (`PhysicalRound`) и «Заполнить
   карту» (`FillMapRound`). Один макет на всех, иначе экраны разойдутся по
   стилю.
2. **Компоновка**: крупная плашка вопроса сверху по центру; тонкая служебная
   строка снизу (секундомер · счёт · след раунда · «Прервать» · ⛶). Углы
   карты свободны.
3. **Варианты ответа** (в «Назвать…» и «Регион — столица») — горизонтальный
   ряд светлых кнопок внизу карты, над служебной строкой. На узком кадре ряд
   переносится в две строки.
4. **Экрана разбора ошибки больше нет.** После неверного ответа карта
   штрихует верный и нажатый регионы, плашка вопроса на ~2 секунды становится
   плашкой ответа («Это Сычуань 四川»), затем раунд сам переходит к
   следующему вопросу. Кнопка «Далее» исчезает. Полный разбор остаётся на
   экране итогов.
5. **Полноэкранность — кнопкой-переключателем** поверх Fullscreen API.
   Решение 2026-08-05 «шапка на всех экранах» не отменяется: в обычном режиме
   шапка стоит, кнопка ⛶ разворачивает только корень раунда.

## Архитектура

Новый компонент `src/features/exercise/RoundStage.tsx` — единственное место,
где живёт компоновка игрового экрана. Раунды-владельцы сохраняют свою логику
и отдают оболочке содержимое слотов.

```
RoundStage
├── плашка вопроса (aria-live="polite")
│     подводка · название цели (с иероглифами) · счёт «7 из 34»
│     └── состояние «ответ»: «Это {цель} {汉字}» после ошибки
├── карта во весь кадр (children)
├── слот вариантов (опционален): ряд кнопок внизу
└── служебная строка:
      секундомер · след раунда (RoundProgressTrail) ·
      «Ответить из списка» (опционален) · «Прервать» · ⛶
```

Границы слоёв не меняются: карта не знает правильных ответов, UI не знает
ключей SVG, домен не знает React. `AppFrame fillsFrame` и закреплённая шапка —
как сейчас.

### Слоты и обязанности

| Слот | Кто заполняет | Примечание |
| --- | --- | --- |
| Вопрос/ответ | раунд-владелец | текст и состояние (вопрос/верно/ошибка) |
| Карта | раунд-владелец | `ChinaMap` / физическая карта с их пропсами |
| Варианты | «Назвать…», «Регион — столица» | в «Найти на карте» пуст |
| Список | только «Найти на карте» | кнопка → панель поверх карты |
| Служебное | RoundStage сам | секундомер, след, «Прервать», ⛶ |

## Поведение

- **Ошибка**: штриховка верного (зелёным) и нажатого (красным) — как сейчас
  через `answerStates`; плашка ответа ~2 с; автопереход. В домене машина
  `feedback → goToNextQuestion` уже есть — меняется только источник перехода:
  таймер вместо кнопки. Константа паузы — рядом с `CORRECT_PAUSE_MS` (500 мс,
  не меняется).
- **Секундомер**: `RoundStopwatch` переезжает в служебную строку всех
  раундов. Только показ; в попытки время уже пишется (`durationMs`).
- **«Ответить из списка»**: кнопка в служебной строке открывает панель поверх
  карты с нынешним `RegionAnswerList`. Фокус уходит в панель; Esc или
  повторное нажатие закрывает и возвращает фокус кнопке.
- **Полноэкранность**: ⛶ вызывает `requestFullscreen()` на корне RoundStage;
  состояние синхронизируется по `fullscreenchange`; Esc — родной выход
  браузера. Если `document.fullscreenEnabled` ложен (iPhone), кнопка не
  показывается.
- **«Заполнить карту»**: та же оболочка; её темп (1,5 с показа неугаданного)
  и счёт попыток на регион не меняются.

## Доступность

- Плашка вопроса — `aria-live="polite"`: смена вопроса и показ верного ответа
  объявляются читалкой (раньше это делал перевод фокуса на заголовок разбора).
- Порядок DOM логический: вопрос → карта → варианты → служебная строка;
  поверх карты элементы ставит только CSS.
- Исход ответа передаётся штриховкой, а не одним цветом.
- Новых цветовых пар нет: плашки берут пару шапки (slate-800 + paper), кнопки
  вариантов — пару бумаги. Появится новая пара — её проверит
  `scripts/validate-tokens.test.ts`.
- Карта с клавиатуры и текстовая альтернатива-список — без изменений.

## Тесты

- Новый `RoundStage.test.tsx`: слоты, полноэкранная кнопка (заглушка API),
  панель списка, live-регион.
- Обновляются тесты четырёх раундов: автопереход после ошибки — фиктивные
  таймеры вместо нажатия «Далее».
- `AnswerFeedback.tsx` и `AnswerFeedback.test.tsx` удаляются.

## Что не меняется

Домен (`round.ts`, прогресс, оценивание), экран итогов, главная, атлас,
коллекции, справочники контента. Новых иероглифов нет — шрифты не
пересобираются. Сетевых запросов не появляется.
