# Факты регионов и контент коллекций

Дата: 2026-08-19. Статус: согласован с владельцем продукта в сессии брейншторма.

## Контекст и цель

Два незакрытых содержательных куска MVP: у всех 34 регионов `facts: []`
(пункт 5 — «карточка с краткой проверенной справкой»), а у всех 12 коллекций
`sourceIds: []` — формальный признак черновика; 11 из них вовсе без текста
(пустые `lead` и `notes`). Цель — наполнить и то и другое проверенным
контентом с документированными источниками. Заполненные коллекции заодно
разблокируют будущий режим «Культура: узнать по фотографии».

## Решения владельца продукта

Приняты в диалоге 2026-08-19:

1. **Объём коллекций — все 12 целиком**: вводка `lead`, 3–4 заметки `notes`,
   непустые `sourceIds`. Фотографии не входят («Фотографии подбирает
   учитель»).
2. **Круг источников**: Большая российская энциклопедия (bigenc.ru) —
   основной для русских форм и фактов; Britannica — второй источник сверки;
   ЮНЕСКО (whc.unesco.org) — для объектов всемирного наследия; официальная
   статистика КНР (stats.gov.cn и профильные ведомства) — для числовых
   фактов, всегда с годом в тексте факта.
3. **UI не входит.** Блок фактов в атласе и человекочитаемые названия
   источников на странице коллекции — отдельная работа: интерфейсные решения
   принимаются по макетам. Контент этой работы становится видимым позже.
4. **Подход — «источники сначала»**: факт пишется только из утверждения,
   реально подтверждённого открытой статьёй реестра; числовые факты — двумя
   источниками. Черновиков «по памяти» с последующей подгонкой источников
   не бывает.

## Секция 1: факты регионов

34 региона × 2–3 факта. Тематическая рамка региона:

- физико-географический факт (положение, рельеф, река, климат);
- культурно-исторический (памятник, традиция, кухня, известное место);
- при наличии яркого — хозяйственный или отличительный (чай, фарфор, порт).

Правила (из CONTENT_GUIDE.md): один факт — одно утверждение; карточка
целиком — до 100 слов; без рейтингов, стереотипов, политических оценок и
статистики без даты. `Fact.title` — короткая тема («Кухня», «Рельеф»),
`Fact.body` — само утверждение, без HTML; у каждого факта непустой
`sourceIds`.

## Секция 2: контент коллекций

12 коллекций: `lead` — 2–3 предложения в духе существующей «Великой стены»;
3–4 заметки `notes` (одно утверждение каждая); `sourceIds` непустые — плашка
«черновик» на странице коллекции снимается сама. У «Великой стены» текст
готов: только источники и выверка существующих утверждений по ним.
Поля `photos` не трогаются.

## Секция 3: реестр источников

Пополняются `src/content/sources.ts` и `docs/sources/sources.md` — синхронно,
по одной записи на конкретную статью или страницу: URL ведёт к утверждению,
а не к сайту вообще. Стиль id — по существующим образцам: `bre-sichuan`,
`britannica-sichuan`, `unesco-great-wall-438`, `stats-china-census-2020`.
Каждая запись несёт `accessedAt` (дата обращения) и `covers`. Ожидаемый
рост реестра — порядка 70–90 записей; это цена проверяемости, принятая
сознательно. Лицензионное правило прежнее: ссылка — источник данных, текст
и изображения не копируются.

## Секция 4: валидация

`src/domain/validate-catalog.ts` расширяется, `scripts/validate-content.ts`
начинает проверять:

- у каждого региона 2–3 факта; у факта непустые `title`, `body` и
  `sourceIds`; каждый id существует в реестре; в `body` нет HTML;
- у каждой коллекции непустые `lead`, 3–4 `notes`, непустой `sourceIds`
  с существующими id.

Ужесточение включается последним коммитом каждой ветки — после наполнения,
чтобы сборка не стояла красной в середине работы. Новые иероглифы в текстах
требуют `npm run generate:fonts` — прогон входит в план обеих веток.

## Секция 5: порядок, ветки, фиксация

Две ветки по очереди:

1. `content/region-facts` — записи реестра для регионов, факты 34 регионов,
   валидация фактов, generate:fonts при необходимости.
2. `content/collections` — записи реестра для коллекций, тексты 12 коллекций,
   валидация коллекций, generate:fonts при необходимости.

В каждой ветке — сводная запись в CHANGELOG.md с причиной и источниками
(требование CONTENT_GUIDE). Сверка идёт по живым статьям (сеть в авторской
фазе); в рантайм приложения сетевых запросов не добавляется.

## Чего в работе намеренно нет

UI фактов и источников (отдельная работа через макеты); фотографий
коллекций; режима «Культура»; правок игровой механики и домена раундов;
правок географии (границы, центры, координаты — уже выверены).
