# Руководство по контенту

## Язык и учебная точность

Основной язык — простой русский, без разговорного упрощения фактов. Китайские названия приводятся иероглифами, пиньинь — со знаками тонов. При первом появлении допустима связка: «Сычуань (四川省, Sìchuān shěng)». Проверяйте варианты названий по двум авторитетным источникам; выбранная учебная форма фиксируется в данных.

## Карточка региона

Одна карточка содержит: название на русском и китайском, пиньинь, административный центр, положение на карте, 2–3 коротких факта, блок «Источник». Общий объём — до 100 слов, один факт — одно утверждение. Не добавляйте неподтверждённые рейтинги, стереотипы, политические оценки и устаревающую статистику без даты.

## Факты

Хороший факт связывает знание с регионом: «Сычуань известна кухней с яркими пряными вкусами». Плохой — расплывчатый: «Это очень интересное место». Для каждого факта добавьте идентификатор источника. Изображения только с лицензией, подходящей для образовательного использования; сохраняйте автора, URL, лицензию и alt-текст.

## Редактура

Перед публикацией проверяются орфография, иероглифы, тоны, названия центров, соответствие карте, возрастная уместность, актуальность и ссылки. Изменение факта записывается в CHANGELOG.md с причиной и источником.
