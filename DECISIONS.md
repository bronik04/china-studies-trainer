# Журнал решений

| Дата | Решение | Контекст и последствия |
| --- | --- | --- |
| 2026-08-01 | Реальную геометрию берём из `@svg-maps/china` с CC BY 4.0 | Пакет даёт чистый вектор с границами и 33 именованными регионами, но без Тайваня. До выбора единого источника с полноценной геометрией Тайваня он остаётся отдельной временной учебной адаптацией из ранее задокументированного CC BY-SA источника. |
| 2026-08-01 | Локальная карта сохраняет реальные границы и цветовые категории утверждённого лицензированного референса | Схематические полигоны не соответствуют визуальному ожиданию владельца. Подписи и легенда удаляются, а доступность и соответствие 34 ID сохраняются. |
| 2026-08-01 | Для карты MVP используется локально адаптированный SVG с CC BY-SA 4.0 | Источник, автор и атрибуция документируются. Карта не делает сетевых запросов и покрывает 34 учебные единицы. |
| 2026-08-01 | Справочник первого инкремента использует две документированные справки | Правительственный источник КНР подтверждает состав 34 единиц, China Internet Information Center — их названия и места размещения правительств. В интерфейсе применяется нейтральный термин «административный центр». |
| 2026-08-01 | Для разработки с субагентами требуется явное разрешение владельца продукта | Субагенты не подключаются автоматически; до разрешения работа выполняется основным исполнителем. |
| 2026-08-01 | Новые функции разрабатываются в отдельных ветках и сливаются в главную после ревью | Главная ветка остаётся проверенной точкой интеграции. Для каждой функции нужны ревью и успешные проверки перед слиянием. |
| 2026-08-01 | Первый инкремент строит справочник и доступный стартовый экран до подключения карты | Так данные и их источники проверяются раньше визуального слоя. SVG не добавляется, пока не зафиксированы лицензия и покрытие 34 регионов. |
| 2026-08-01 | В MVP используется SVG-карта | Области предсказуемо интерактивны, приложение может работать офлайн. Нужны лицензия и проверка соответствия регионов. |
| 2026-08-01 | Прогресс хранится локально | MVP не обрабатывает персональные данные на сервере. Нет синхронизации между устройствами. |
| 2026-08-01 | Тренируем 34 единицы провинциального уровня | Это соответствует образовательной задаче; тип региона хранится явно, чтобы не маскировать различия. |
| 2026-08-01 | Первый набор — «Провинции и столицы» | Узкий фокус позволяет проверить механику прежде чем добавлять другие темы. |
| 2026-08-01 | Нет публичного рейтинга | Снижается давление на школьников и риски приватности. |

Новые решения добавляйте сверху или в хронологическом порядке с датой, альтернативами при необходимости и явными последствиями.
